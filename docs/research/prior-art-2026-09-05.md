## Closest prior art (researched 2026-09-05)

Claude Desktop (MCP + Cowork Dispatch) is the analogy people reach for: "any agent talks to any other." That is **not** what Desktop ships. MCP is agent→tools. Dispatch is phone→the same Claude on the desktop.

### Cross-machine / token-ish (the interesting pile)

| Project | What it is | vs Holler |
| --- | --- | --- |
| **Heterogeneous agent frameworks** | Most buses assume one connector (MCP on every agent, ACP on every agent, or "everyone is Claude"). | **First requirement.** OpenCode today; Claude and others unchecked on holler-server#1. A new harness is an adapter, not a new plane. |
| **[c2c](https://c2c.im/)** ([clankercode/c2c](https://github.com/clankercode/c2c)) | Heterogeneous CLIs (Claude, Codex, OpenCode, Grok, Pi, Kimi, agy, Hermes). Local file broker + optional HTTP/WS relay with `--token`. `c2c send` / `monitor` / `status`. **Alpha.** | Strongest product match. Cross-machine is inbox **sync/poll**, not a live WS circuit. Wake is uneven (OpenCode/Pi guaranteed; Claude/Grok often idle-deaf). **License: GitHub `null`; npm wrapper MIT — do not vendor.** |
| **[ai-crew-sync](https://github.com/joaquinbejar/ai-crew-sync)** | Postgres bus, `token issue` / revoke, presence, tasks, MCP HTTP. Cross-user and cross-machine. | Token identity is real. Still MCP-shaped; far box must be an MCP client. No ACP cancel as the product. |
| **[swarmcode](https://github.com/spranab/swarmcode)** | Redis channel so **Claude Code on different machines** can message. | Cross-machine yes. Claude-only. Shared Redis, not a minted join token. |
| **[Harness Remote](https://github.com/giuliastro/opencode-remote-android)** | Control plane over native OpenCode / Claude / Codex / Pi sessions across devices. | Remote **observe/resume/handoff**, not a talk circuit. You attach to *their* session. |
| **[opencode-orchestrator](https://github.com/autonomica-xyz/opencode-orchestrator)** | CLI against `opencode serve` HTTP on several hosts. | You configure URLs (SSH-shaped). No join token, no other harnesses. |
| **Claude Code [cross-session messaging](https://code.claude.com/docs/en/cross-session-messaging)** | `SendMessage` across machines via Anthropic Remote Control + per-session token. | Official, works. **Claude-only**; other-machine traffic through Anthropic. |
| **[Buzz](https://github.com/block/buzz)** | Relay as home; ACP body; presence and `!shutdown` are messages. | Same *layer*. Not a clone (no Nostr/nsec). Apache-2.0. |
| **[Herdr](https://herdr.dev)** | PTY runtime; local socket; multi-remote ([herdrdev/herdr#515](https://github.com/herdrdev/herdr/discussions/515)) is one TUI over many Herdr servers. | Closest *sibling*. Hub body, not the bus. Far box need not run it. Apache-2.0. |

### Same machine (not the problem)

[agent-mesh](https://github.com/mubashir1osmani/agent-mesh), [agent-bus](https://github.com/MustaphaSteph/agent-bus), [agent-comms](https://github.com/ExaDev/agent-comms), [CCCOG-MCP](https://github.com/WarmBed/CCCOG-MCP), [agent-channel](https://github.com/fl4p/agent-channel), [agent-message](https://github.com/slima4/agent-message), OpenCode's in-process cross-session plugin — files / SQLite / localhost TCP. One host.

[a2a-bridge](https://github.com/firstintent/a2a-bridge), [acp-bridge](https://github.com/xiwan/acp-bridge) — HTTP/A2A gateways in front of local CLIs. Call an agent; not a session roster with cooperative interrupt for meta-O.

herdr-mirror / herdlord / herdr-mx — attach or dashboard remote **Herdr** panes. PTY view. Workers cannot holler back.

Google A2A — cross-org agent cards, not "OpenCode on a homelab joins with a token."

## Why the gap looked real, as of 2026-09-05

A small server that mints a join token, a client on a box with no Herdr, OpenCode (then Claude)
as adapters, interrupt as ACP cancel with the session still alive, and meta-O talking over CLI
without SSH — the 2026-09-05 survey found no single project covering all of that at once. c2c is
the tool to read. ai-crew-sync is the token cousin. Claude's own messaging proves cross-machine
*for Claude specifically*. Buzz is the architecture. Herdr is the hub body. None surveyed at the
time matched the full tuple.

See [`landscape-2026-09-07.md`](landscape-2026-09-07.md) for the follow-up exploration two days
later — A2A v1.0, AgentCore Gateway, AGNTCY SLIM, and a materially different picture on the
agent-to-agent-interop side of this question — and
[`positioning.md`](positioning.md) for where that leaves Holler's own honest claim.

## Added 2026-09-25 — replies to the "shared board" thread

Nicolas Bustamante asked who is building a fast, permissioned, persistent agent board
(`post` / `get` / `reply` / `subscribe` from the CLI), and said agent email is too slow:
<https://x.com/nicbstme/status/2103355485973848128>. The thread had 177 replies the day it
was sampled. The common answer was [A2A](landscape-2026-09-07.md), already surveyed on
2026-09-07 (Google ADK's A2A docs, `a2aproject/A2A`, and the Swift SDK
[viae-swift-a2a](https://github.com/SnoobieJunes/viae-swift-a2a) are implementations of that
spec, not a new plane). Holler was also in the thread. The rows below are the other named
tools. Pages were read the same day; a row with no public page is the author's claim only.

### Checked against a public page

| Project | What it is | vs Holler |
| --- | --- | --- |
| **[October Bus](https://bus.october.dev)** ([october-dev/october-bus](https://github.com/october-dev/october-bus)) | Local-first Go daemon plus SQLite. Agents discover peers, send durable requests and replies, and claim shared tasks. MCP or native adapters. A **scope token** is the credential. **Apache-2.0.** Developer preview (`0.1.0-next`). | Closest new sibling to the board the question asked for. Codex has a verified adapter; Claude Code, Cursor, and OpenCode are early. Delivery is **pull**: accepting a request does not interrupt a live turn. Cross-machine is not in the open tree — the README leaves remote transport as future work, and hosted multiplayer is listed as coming soon. Not a minted join onto an already-running ACP session. |
| **[MCP Agent Mail](https://mcpagentmail.com/)** ([Dicklesworthstone/mcp_agent_mail_rust](https://github.com/Dicklesworthstone/mcp_agent_mail_rust)) | Shared inbox, advisory file reservations, searchable audit log. SQLite + Git. MCP tools and a robot-mode CLI (`am`). Author ([@doodlestein](https://x.com/doodlestein/status/2103383674544894284)) says daily use across Claude Code, Codex, and Gemini. **MIT.** | Same-machine coordination fabric. Identity is a memorable project-scoped name, not a revocable join token. No outbound circuit, no attach to a session that is already running on another box. |
| **[SW4RM](https://github.com/rahulrajaram/sw4rm)** | gRPC registry, router, and scheduler. ACK lifecycle, negotiation, crash-safe handoff, an A2A gateway, five SDKs. **Apache-2.0.** Author ([@rahulrajaramio](https://x.com/rahulrajaramio/status/2103473092605722802)) says he uses it and that the docs are stale. | Agents join by registering an `agent_id`. The README's story is an SDK participant of the registry, not an existing CLI session that keeps running and presents a minted token. |
| **[Paperclip](https://paperclip.ing/)** ([paperclipai/paperclip](https://github.com/paperclipai/paperclip)) | Org chart, goals, tickets, per-agent budgets, and heartbeats over any agent that can take a heartbeat (Claude, Codex, Cursor, OpenCode, Hermes, OpenClaw, Pi, or a shell/webhook). Self-hosted Node process with embedded Postgres. **MIT.** | A control plane that schedules agents. It does not attach to a live coding session and interrupt that turn. Heartbeat wake is the opposite of Holler's "the session is already there, talk to it." |
| **[IAP v1.0](https://github.com/MMVFIRM/iap-v1.0)** | Inter-Agent Protocol, Richard Anthony Aragon. A teacher distills a small policy packet (97-byte policy, or 241-byte policy plus relational atlas), a recipient grounds it against local observations, and the packet is absorbed into the recipient's own parameters. The exported recipient then runs with the packet removed. CLI is `python -m iap`. **No repository-wide license**; the LICENSE file says the choice is still pending. | Missed on the first pass through the thread. The name reads like a messaging standard. The README says it is not one: it studies finite symbolic Convention Relay tasks, and it is not a universal agent-communication protocol. No roster, no join token, no `post` / `get` / `reply` board, no attach to a running coding session. |

### Pointed at, and not this chart

- **Beads**, in the same thread, as the queue next to Holler — a task list, not the circuit.
- **[AuthBoundry](https://www.authboundry.com/)** — an authority/policy boundary for autonomous actors. The reply is only the URL. It decides what an actor may cause; it is not a board.
- **Converso / Exchange** ([@christobarley](https://x.com/christobarley/status/2103393522212598031)) — explicitly the other problem: a permissioned inbox for a customer's agent talking to a business, not a board among your own agents.
- **Nostr**, **Slack / Telegram / Discord**, and **agent email** — transport suggestions. Buzz already sits on a Nostr-shaped relay. Email is what the question was trying to get away from.
