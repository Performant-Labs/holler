## Summary

BLOCK, with 3 blocks and 7 warns.

Revision 3 answers both revision-2 blocks. I re-checked each one against the code and the issues:
- Each verb's clap struct now lives in its own verb file (decision 10), so no sibling story needs a frozen file to add its positionals.
- Decision 2's closed set holds every kebab-case code the epic and its siblings name (I grepped #633-#667), plus the infrastructure variants and an open variant.
- Revision 2's warns 3, 4, 7, 8 and 11 are fully answered; warns 5, 6, 9 and 10 mostly.

The three blocks come from what revision 3 newly freezes, plus one gate that every revision has carried:
1. The frozen verb/output seam does not type-check, and it cannot reach stderr.
   - `run(args, ctx: &VerbCtx)` cannot write to `ctx.out` or `ctx.err`; I compiled the shapes and got E0596.
   - `emit`, `emit_stream` and `emit_usage_error` take only `out`, so a text-mode refusal or a JSON-mode diagnostic cannot reach stderr through the injected writers.
   - #660 must keep these signatures while six wave-3 verb stories call them.
   - The `emit` signature is the one I proposed in revision 2's row 6. The missing error writer is my mistake.
2. `ProfileScope::resolve(&ProfileName, &PaneName) -> ResolvedScope { profile, member: bool }` cannot express "no pane name means every pane of P". #643, #646, #647, #648, #663 and #638 all require that of the trait.
3. AC 1's `cargo fmt --check` cannot pass.
   - 176 of the workspace's 195 `.rs` files fail it on origin/main, and CI does not run it.
   - Formatting `control_server.rs` and `serve.rs` takes them to 1161 and 949 lines, past AC 1's own 900-line gate.
   - Both earlier reviews missed this.

All three are brief edits, not a redesign.
