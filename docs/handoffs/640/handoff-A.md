**Verdict:** PASS

## Summary

PASS. The plan builds on the right objects and introduces no parallel ones:

- **Shared types.** It uses `holler_pane`'s `PaneError`, `GridPos`, `PaneId` and `Key`, so there is no second error, grid or key type.
- **Its one open code.** `grid-unreachable` is declared in its own file through `RefusalCode::from_static` (ADR-0021 §9).
- **Testkit vocabulary.** `GRID_UNREACHABLE` and `SUPPORTED_VERSIONS` mirror the testkit's values and are pinned equal by test. That is the option the testkit's own `ASSUMPTION (#640)` offers.
- **The conversion.** The spike's `derive()` tree walk is ported as the only conversion.
- **Placement.** The three new modules are justified: the crate is an empty skeleton, and ADR-0021 §10 and epic decision 7 make it the only home of the conversion.
- **Dependencies.** The direction holds: `holler-pane` only, the testkit as a dev-dependency, and no `holler-hub` import (ADR-0021 §5). Inside the crate, `plan` and `protocol` each depend on `layout`, with no cycle.
- **Pure core.** The I/O-free core matches `holler-pane`'s pure engines.
- **Size.** No file comes near the 900-line gate.

The 14 findings are all `warn`:

- **W-1 to W-6** are for T and F to settle in RED and GREEN without renaming any pinned item.
- **W-7 to W-14** are forward-compat items for the parts 2 and 3 briefs and for neighbouring stories (#644, #647, #649, #664). None of them changes part 1's pinned API.

Plan is otherwise consistent with existing patterns. Checks that passed:

- **One-line messages.** Error mapping follows `send_over`'s result-or-error shape (control.rs:477-518). An unknown Herdr code or a garbled reply becomes `unavailable` (ADR-0021 §9). Typed text never reaches an error message (AC 16).
- **Rows first.** The planner's choice of rows before columns, and its ratios `1/(n - k + 2)`, reproduce the spike's verified 2x4 build exactly. Positions never depend on ratios (AC 4).
- **Deferred ADR rows.** Moving the ADR-0021 §9 and §10 rows to part 3 is acceptable. §10 hands the extent decision to #640, §9 already covers open codes an adapter declares, and no verb can raise `grid-unreachable` before #649 wires the adapter. #649 depends on #640.
- **`last_lines`.** Re-implementing it is justified. The testkit's copy is private and a dev-dependency only, and AC 20 pins the behaviour as identical.
- **Allow-list.** Leaving `layout.apply`, `pane.move` and `pane.swap` off the method list is stricter than spike §12 requires. That is consistent with `HerdrPort`, which has no run method.
