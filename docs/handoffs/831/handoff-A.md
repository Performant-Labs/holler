## Questions for the operator (ask now)

1. **What should an adopted Claude pane record as its model and effort?** A pane's `pane.env` holds OpenCode values (`OC_MODEL`, `OC_EFFORT`, `OC_DEFAULT_AGENT`), and `relaunch` passes the model id and effort to `claude`. Do the fleet's typed-in Claude panes carry a usable `OC_MODEL` (an Anthropic model) in `pane.env`? If not, is it acceptable to record the value as read and have the report warn, or should the import refuse a pane whose model is not an Anthropic one? Default I would take: copy as read, warn when the provider is not Anthropic, never copy an agent.
2. **Which command should the report name if the undo of an extension fails?** There must be one that removes only this run's records and never `fleet`. Is there a verb you would use, or should the message just list the records and `holler pane list`?
3. **Is a `ps -t <tty>` call (or `/proc`) acceptable in the host adapter?** tmux has no foreground-group format, so D2 needs it. Linux and macOS both have `ps -t`; `/proc` is Linux only. Default: `ps`, through the bounded runner.
