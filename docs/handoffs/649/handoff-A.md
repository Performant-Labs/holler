## Summary

**Verdict: PASS, with no blocks and fifteen warns.** Eleven of them are binding on T and F.

**The objects and the layers are right.**

- The plan fills #670's `Wiring`, which ADR-0021 ruling 1 names as the one place adapters are built.
- It reuses `StoreScope` (#663) and `SystemProber`.
- It keeps every adapter out of `holler-hub`, as ADR section 5 requires.
- It puts the store client CLI-side, over the existing `PaneReply` and params types.
- No object it adds has an existing analogue it should extend instead. No `PaneStore` or `ProfileStore` runs over the control socket today, and the `tui_session` resolver is the precondition the OpenCode adapter leaves to wiring (E31, E32).

**What the warns are about.** Each covers something the plan leaves unsaid, not a wrong choice:

- **Scenario isolation (W-1).** Under D7, every OpenCode process the scenario starts inherits the private tmux server's environment. D10's four guards scratch Herdr, the state dir and the socket, but not that environment. Without a fifth guard, a scenario `launch` can read the developer's OpenCode config and auth, and write into their session store. That happens inside the verb, before D12's model guard can run.
- **Scope (W-2, W-3, W-8, W-11).** D2 with AC 1, D11, and the size of the wiring all force edits to files the Blast radius does not list. Each edit is approved here for the one purpose named, as #651's `plugins/*` exception was.
- **Correctness traps (W-4, W-5, W-9):**
  - a delegating `HarnessPort` silently drops #642 part 3's two default-armed methods;
  - a registry lookup by pane id alone can name another Herdr session's pane;
  - `ControlError` cannot tell a lost reply from a failed send, so the client needs one mapping table.
- **Reuse and records (W-6, W-7, W-12):**
  - the clients run the test kit's store conformance suites, as ADR section 2 requires of every real implementation;
  - seven ADR-0021 sentences that hand #649 work it no longer does are amended in the same change;
  - D8's coupling is pinned in the default run, not only in the opt-in scenario.
