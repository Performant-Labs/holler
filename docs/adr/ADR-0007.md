# ADR 0007 — Join token, then a body credential

**Status:** accepted (§1/§3 amended 2026-09-11 — see below)
**Issue:** [#8](https://github.com/Performant-Labs/holler/issues/8)
**Date:** 2026-09-09
**Depends on:** [ADR 0001](ADR-0001.md), [ADR 0004](ADR-0004.md), [ADR 0005](ADR-0005.md)
**Supersedes:** `holler-server` ADR-0003 (join token, then a client credential)
**Superseded in part by:** [ADR 0018](ADR-0018.md) (issues [#322](https://github.com/Performant-Labs/holler/issues/322)/[#323](https://github.com/Performant-Labs/holler/issues/323), 2026-09-11) — §1's minted **credential** and §3's "present the credential every reconnect" are replaced by a registered **public key** and a proof-of-possession challenge-response. The text below is left as an accurate record of the original decision, not rewritten; §2, §4, and §5 (the join/authenticate split as separate methods, the `hub token …` operator surface, and "no client aliases") are unaffected and still stand.

## Decision

Pairing a body to a hub is **two steps**, and the two steps are **two different JSON-RPC methods**, not two spellings of the same frame: a short-lived **join secret**, minted by the operator and redeemed once, buys a long-lived **credential**; the credential, not the secret, authenticates every later connection. This is the device-pairing pattern `holler-server` ADR-0003 already chose; what changes here is the wire (JSON-RPC v2, ADR 0004) and the operator surface (`hub token …`, ADR 0003 of this repo).

1. **Mint** — `holler hub token mint --label LABEL [--ttl 24h]`. A **label**, not a machine name, is chosen at mint (grammar and per-hub uniqueness are ADR 0005's, not repeated here). The join secret is a 256-bit CSPRNG value, shown once, never logged.
2. **Join** — `circuit/join {secret, hostname}` is legal **only as the first frame on a fresh socket**, and only on a socket that has not already sent `circuit/authenticate` — a socket sends one or the other, never both. On success the hub replies `{client_id, credential}` and **closes the socket**. Join never leads into talk on the same connection; it is a one-shot bootstrap, and a lost or expired join secret is a new mint, not a retry of the old one.
3. **Authenticate** — `circuit/authenticate {token_id, credential, hostname}` is the first frame on every normal (re)connect, presenting the **credential** — never the join secret, and never in a logged URL query string. Success moves straight into `circuit/hello` (ADR 0004) and then talk.
4. **List / delete / ping** — the operator noun stays the **token**, not a separate "client" object: `hub token list` (unused and bound rows, machine hostname when bound, never a secret), `hub token delete ID` (aliases `rm`/`remove`; invalidates an unused secret or revokes a bound credential and drops the socket), `hub token ping ID` (application ping/pong on the live socket; hostname + RTT).
5. **No `client` aliases.** `holler-server`'s `client list` / `client detach` were aliases of bound-token `list`/`delete`, kept only because the old split repo also had a `holler-client` binary calling itself "the client." That binary is gone (ADR 0001); this repo has no `client` noun to alias, so those aliases are not carried forward. `hub token …` is the only surface.

## Why

Join secrets leak into chat logs, shell history, and screenshots; a credential does not need to, because it is set once by `body join` and read from local state thereafter. Splitting mint-time material from connect-time material lets an operator revoke a single compromised or retired body (`token delete`/`revoke`) without rotating every other body's credential, and lets an unused, never-redeemed secret expire on its own without touching anything already bound. Folding "client" into "token" removes a second table that would otherwise say the same thing about the same row in different words.

## Consequences

- `crates/holler-hub/src/token.rs` is the single store for both secret and credential state, keyed by `token_id`; both are kept at rest as `HMAC-SHA-256(pepper, value)`, never in the clear (the pepper itself is [ADR 0008](ADR-0008.md)).
- `circuit/join` and `circuit/authenticate` are separate JSON-RPC methods (ADR 0004's envelope), not a shared frame type distinguished by a payload flag — a socket's very first message already says which path it is on.
- The CLI surface (`hub token mint|list|delete|ping`) is normative in [ADR 0003](ADR-0003.md); this ADR does not repeat the flag table, only the pairing model those verbs implement.
- Label choice and uniqueness at mint are [ADR 0005](ADR-0005.md)'s, referenced here rather than re-decided, because the label is also the addressing namespace root.

## Not decided here

- Label grammar and per-hub uniqueness — [ADR 0005](ADR-0005.md).
- How secrets and credentials are hashed at rest, and the pepper — [ADR 0008](ADR-0008.md).
- Transport security for the socket carrying `circuit/join`/`circuit/authenticate` — [ADR 0006](ADR-0006.md).
