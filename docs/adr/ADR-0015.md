# ADR 0015 — License AGPL-3.0-or-later; outside PRs welcome; AI-disclosure policy

**Status:** accepted
**Issue:** [#16](https://github.com/Performant-Labs/holler/issues/16)
**Date:** 2026-09-09
**Supersedes:** `holler-server` ADR-0016, `holler-client` ADR-0004 (both: license AGPL-3.0-or-later, outside PRs now welcome)

## Decision

Holler is licensed **AGPL-3.0-or-later** — the FSF's own recommended boilerplate ("or (at your option) any later version," not `-only`) — and outside pull requests are welcome, under the disclosure rules this repo's own `CONTRIBUTING.md` already states. The two legacy repos made this decision **twice**, once per repo, because each had its own `Cargo.toml` and its own `CONTRIBUTING.md` to update; this repo makes it **once**, because there is one binary, one `LICENSE`, and one `CONTRIBUTING.md` to keep consistent.

1. **License:** `LICENSE` at the repo root is the verbatim AGPL-3.0 text from the FSF; `Cargo.toml`'s `license` field is the SPDX identifier `AGPL-3.0-or-later`.
2. **Outside PRs are welcome**, with a lightweight flow: fork → branch → PR against `main` → CI must pass (branch-protected, both required jobs green) → maintainer review. No CLA, no RFC process — this project's scale does not warrant either.
3. **AI-disclosure policy** (this repo's own addition, beyond what either legacy repo's license ADR covered): a PR or issue substantially drafted or generated by an AI agent must say so; disclosure does not lower the review bar — the human submitter is fully accountable, exactly as if they had written it by hand; and a bug report specifically must be personally verified by the human submitter (reproduced themselves, or watched an agent reproduce it and confirmed the evidence) before filing — "the agent said so" is never a substitute for a checked repro.
4. **One repo, one policy.** There is no longer a "server ADR says X, client ADR says the same X independently" split to keep in sync — `docs/adr/README.md`'s single index and this repo's single `CONTRIBUTING.md` are the only places this policy is stated.

## Why

The **"Holler Cloud" argument survives the merge unchanged**: this project's differentiator, spelled out in the README's comparison against hosted "remote control" competitors, is self-hosting with no cloud intermediary at all. A permissive license does not protect that positioning — anyone could fork Holler, run it as a hosted service, and wrap it in a closed "Holler Cloud" layer without contributing anything back, recreating exactly the cloud-intermediary model this project exists as an alternative to. AGPL-3.0's network-use clause closes that gap: a modified version used to provide a network service must make its source available to the users of that service — precisely the scenario a permissive (MIT/Apache-2.0, the Rust-ecosystem convention this project deliberately does not follow) license would leave open. Welcoming outside PRs, and pairing that openness with an explicit AI-disclosure policy, follows from the same posture this project already takes toward its own commit history: every agent-assisted commit already carries a `Co-Authored-By:` trailer, so extending that same disclosure convention to issues and PRs from outside contributors is consistency, not a new principle.

## Consequences

- `LICENSE` (root) is the canonical, verbatim AGPL-3.0 text; `Cargo.toml`'s workspace `license` field reads `AGPL-3.0-or-later`.
- `CONTRIBUTING.md`'s "Code contributions" section states the fork → branch → PR → CI → review flow with no CLA/RFC process, and its "AI-assisted contributions" section states the three disclosure rules in point 3 above, including the bug-report verification checkbox in the issue template.
- `README.md`'s "Status and license" section and any "why this is different" comparison table no longer say `Proprietary`.
- This does not change crates.io publishing plans — the `holler` crate name being already taken (ADR 0001's naming note) is an unrelated, still-standing blocker, not a licensing question.

## Not decided here

- Whether to eventually publish to crates.io — blocked on the naming collision recorded in [ADR 0001](ADR-0001.md), not on licensing.
- Any change to the wire protocol, versioning policy, or release mechanics.
