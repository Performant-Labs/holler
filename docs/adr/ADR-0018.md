# ADR 0018 — Hub identity (X25519) and body proof-of-possession (Ed25519) replace the join credential

**Status:** accepted
**Issue:** [#19](https://github.com/Performant-Labs/holler/issues/19) (claims this reserved slot for [#322](https://github.com/Performant-Labs/holler/issues/322)/[#323](https://github.com/Performant-Labs/holler/issues/323); slot #17/ADR-0016 was independently claimed by "Hub-enforced turn and spend caps" while this ADR was in flight)
**Date:** 2026-09-11
**Depends on:** [ADR 0004](ADR-0004.md), [ADR 0006](ADR-0006.md)
**Supersedes (in part):** [ADR 0007](ADR-0007.md) §1/§3 (the credential-minting/-presenting halves of the pairing model) and [ADR 0008](ADR-0008.md) §1–2 (hashing a shared credential at rest). Both ADRs' text is left as an accurate historical record of what was decided at the time; this ADR is the amendment, not a silent rewrite of either.

## Decision

**#322 — hub identity.** The hub gets a long-lived **X25519** static keypair, generated on first `hub serve`/`hub token mint` and persisted at `0600`, never logged. `hub token mint`'s join line (and its `--json` output) carries the public half; `body join --hub-key HEX` **pins** it, out-of-band, the same physical channel that already carries the one-time join secret. Every later `circuit/hello` a hub sends carries this same key; a body compares it on **every** connection and hard-fails on any mismatch — no prompt, no trust-on-first-use, ever.

**#323 — proof of possession replaces a bearer credential.** `circuit/join` registers a body-generated **Ed25519** public key instead of returning a credential. `circuit/authenticate` becomes a nonce challenge — the hub issues a fresh, single-use nonce; the body signs a transcript (`protocol_version ‖ role ‖ nonce ‖ token_id ‖ advertised_url`) with its private key and answers `circuit/prove`. No secret crosses the wire after the one-time join secret is redeemed, ever again, on any reconnect.

**Why two different primitives.** X25519 is Diffie-Hellman-only; it cannot produce a signature. Ed25519 is a signature scheme. `circuit/prove` needs the body to *sign* something, so the body must use Ed25519. The hub, in this design, never signs anything — it only mints nonces and verifies a body's signature — so X25519 is sufficient for the hub, and is deliberately chosen as the pre-message static key a future Noise XK handshake ([ADR 0006](ADR-0006.md)'s v2 native-TLS successor, tracked in [#321](https://github.com/Performant-Labs/holler/issues/321)) will need. This is not an inconsistency between the two issues — it is each side using the minimum primitive its own role actually requires, chosen so the future handshake is an incremental addition rather than a redesign.

## Consequences

- `crates/holler-hub/src/token.rs`'s `Record` drops `credential_hmac` and gains `body_pubkey: Option<String>` — a **public** key, kept in the clear, not hashed. A stolen token store now yields no secret material for a bound token at all (ADR 0008's HMAC-pepper machinery is narrowed to exactly the join secret — see below — rather than protecting a value an attacker could otherwise present directly).
- ADR 0007 §1–3's "join secret → credential → present the credential every reconnect" model is replaced by "join secret → registered public key → prove possession every reconnect." ADR 0007's §4/§5 (the `hub token list|delete|revoke|ping` operator surface) and its "no client aliases" decision are **unaffected** and still stand as written.
- ADR 0008's pepper/HMAC machinery **remains**, narrowed to exactly the case it was always good at: the join secret is still a one-time bearer value until redeemed, and is still hashed at rest under the pepper (§1–3 of that ADR, unchanged). What is gone is hashing a *second*, long-lived bearer value (the credential) — because there no longer is one.
- `docs/protocol/v2.md` §3–4 and its Hello document are updated for the new wire shapes (`circuit/join`, `circuit/authenticate`, the new `circuit/prove`, and `hub_pubkey` on a hub's hello).
- This is a wire break, landed together with [#322](https://github.com/Performant-Labs/holler/issues/322) as one PR (the two issues are one break, filed separately only because identity and proof-of-possession are separable concerns) — free before [v0.1.0](https://github.com/Performant-Labs/holler/issues/319), permanently expensive after bodies are paired in the field.

## Not decided here

- The Noise XK handshake itself, session encryption, forward secrecy, SAS — [#321](https://github.com/Performant-Labs/holler/issues/321).
- Transport confidentiality, the loopback-`ws`-only rule, and the tailnet/proxy deployment path — [ADR 0006](ADR-0006.md).
- The join/redeem pairing model's operator surface (`hub token mint|list|delete|revoke|ping`) — [ADR 0003](ADR-0003.md)/[ADR 0007](ADR-0007.md) §4–5, unaffected by this ADR.
